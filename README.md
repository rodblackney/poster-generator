# poster-generator

An endless wall of generated posters. Drag to explore, hover for the layout grid, click a poster to edit its text, remix it, change colours and export a PNG.

11 styles: Specimen, Glow, Habits, Tiles, Symbols, HUD, Thermal, Online, Globes, Blocks, Shallow.

Single file, no build step: open `index.html` or serve the folder (`python3 -m http.server`).
